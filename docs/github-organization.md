# GitHub organization

Owner reference for the [N.C.N.G. GitHub organization](https://github.com/ncngmodelrailroad).
Keep this guide public-safe. Store applications, legal documents, recovery codes,
and billing records outside GitHub repositories and issues.

## Public presence

The organization profile belongs in `profile/README.md` in the public
[`ncngmodelrailroad/.github`](https://github.com/ncngmodelrailroad/.github) repository.
The `.github` directory in this website repository does not control that profile.

Keep the profile short: mission, an existing layout photo, website links for
visiting and supporting the layout, and a link to the website contribution guide.
Use the website's current organization details, not separate visiting hours,
admission claims, or donation instructions. Do not describe the organization as
GitHub-verified until enrollment is approved.

The website repository's About section should point to
`https://ncngmodelrailroad.org/`. Keep GitHub and Pages CMS links under the
`ncngmodelrailroad` owner.

## Nonprofit enrollment

As of September 30, 2026, the organization reports the **GitHub Free** plan.
This guide prepares enrollment; it does not establish an application submission
or approval.

GitHub offers eligible, verified nonprofits **GitHub Team at no charge**, or a
25% discount on Enterprise Cloud. Team is the intended option for this
organization. Do not select a paid upgrade as a substitute for nonprofit
approval. The public website can continue using GitHub Pages on Free.

An authorized officer must confirm the eligibility statements: nonprofit,
nongovernmental, nonacademic, noncommercial, and nonpolitical. Gather current
proof of nonprofit status, such as the IRS determination letter or accepted
government registration documents. A public EIN or this guide does not replace
the portal's documentation requirements.

### Apply and activate

1. An organization owner opens the [GitHub for Nonprofits portal](https://nonprofits.github.com/getting-started).
2. Sign in, review the requested OAuth access, and authorize it only with owner
   approval. Select `ncngmodelrailroad`.
3. If GitHub does not already recognize the organization as validated, complete
   the validation application with the confirmed legal name, registered address,
   eligibility statements, and supporting documents. Review before submitting.
4. Watch for the application decision in the organization owner's email.
5. After approval, return to the portal and choose **Continue with Team**.
   GitHub says to allow up to a week for the free Team upgrade.
6. Confirm that organization billing shows Team with the nonprofit benefit
   applied. Record the approval and any renewal instructions privately.

Submission, approval, and benefit activation are separate milestones. Update
the status here only after verifying the corresponding result.

Sources: [GitHub nonprofit quickstart](https://docs.github.com/en/nonprofit/quickstart)
and [claiming free Team](https://docs.github.com/en/nonprofit/nonprofit-teams-plan/getting-started-with-the-github-team-plan-for-nonprofits).

## Owner handoff and access

These are owner decisions, not permission to change settings automatically:

- Arrange a trusted backup owner with an individual account. Do not share a
  login or publish an owner roster here.
- Before requiring organization-wide two-factor authentication, check member
  and outside-collaborator readiness and recovery arrangements.
- Keep access limited to the repository and role needed. Review repository
  creation permissions before adding more members.
- Keep the website's required Build check and blocked force pushes/deletions.
  Use pull requests for website changes and address accessibility failures.
- Keep public contact details on the website. Confirm privately who receives
  billing, nonprofit-program, and account-recovery notices.

Enrollment does not require new teams, private repositories, paid products,
or additional website services.
