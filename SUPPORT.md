# Support

Need help with the N.C.N.G. website? Here's where to go:

## I want to edit website content

Follow the [GitHub editing guide](CONTRIBUTING.md#editing-content-no-coding-required)
to propose a change through a pull request. No local coding tools are required.

Site admins can also use [Pages CMS](https://app.pagescms.org/ncngmodelrailroad/ncngmodelrailroad.org).
It defaults to saving to protected `main`, so it is not the editing path for
non-admin volunteers.

> Need access? Follow [Getting access](CONTRIBUTING.md#getting-access).

## I found a bug or something looks wrong

[Open a bug report](https://github.com/ncngmodelrailroad/ncngmodelrailroad.org/issues/new?template=bug-report.yml) on GitHub with details about what you see and what you expected.

## I want to request a content change

[Open a content update request](https://github.com/ncngmodelrailroad/ncngmodelrailroad.org/issues/new?template=content-update.yml) describing what needs to change.

Issues are public. Keep personal details and nonprofit paperwork out of them.

## I want to make code changes

See the [Development Guide](docs/development.md) for setup instructions and the [Contributing Guide](CONTRIBUTING.md) for how to submit changes.

## General questions

Use the [Contact page](https://ncngmodelrailroad.org/contact/) for current contact
details and questions about the layout.
